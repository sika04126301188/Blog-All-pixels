Preguntas frecuentes

Dudas habituales

¿Puedo usar una plantilla gratis en la web de un cliente y cobrarle?

Sí. Puedes cobrar por tu trabajo (diseño, desarrollo, personalización). Lo que no puedes es vender la plantilla en sí. Con la licencia Gratis, la web debe mantener el crédito a All Pixels.

¿Cuántos proyectos puedo hacer con una licencia?

Ilimitados, tanto con la Gratis como con la Pro. La licencia Pro es para una persona: si varias personas de tu equipo trabajan con el recurso, cada una necesita su licencia.

¿Puedo subir el proyecto a GitHub?

A un repositorio privado, sí. A uno público no, porque cualquiera podría descargar la plantilla. Si tu proyecto final debe ser público, quita del repositorio los archivos originales de la plantilla o escríbenos.

¿Qué pasa si cancelo la suscripción All-Access?

Todo lo que descargaste mientras estaba activa sigue cubierto por la licencia Pro para siempre. Dejas de recibir recursos nuevos y actualizaciones.

¿Las fotos de las demos están incluidas?

No siempre. Las fotos, iconos y tipografías de terceros tienen sus propias licencias. El README de cada plantilla indica qué se incluye y de dónde viene cada recurso.

¿Y los componentes y snippets de GitHub?

Los componentes y fragmentos de código pequeños que publicamos en nuestro GitHub usan la licencia MIT, indicada en cada repositorio. Las plantillas completas usan siempre las licencias Gratis o Pro.
