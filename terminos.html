All Pixels es una plataforma que ofrece plantillas web, componentes y código front-end, gratuitos y de pago. Al navegar por el sitio aceptas estos términos. Si no estás de acuerdo, no uses el sitio.

3. Uso del sitio

Te comprometes a usar el sitio de forma lícita. En particular, no puedes:

  • Descargar recursos de forma masiva o automatizada (bots, scraping) ni saltarte las medidas técnicas de protección.
  • Compartir tus datos de acceso o archivos de pago con otras personas.
  • Introducir virus o código malicioso, o intentar acceder a zonas no autorizadas.
  • Usar el sitio o sus recursos para actividades ilegales o que vulneren derechos de terceros.

Podemos suspender el acceso a quien incumpla estas normas.
